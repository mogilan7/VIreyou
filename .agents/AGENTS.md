# Правила ИИ-агента для проекта VIreyou

## Работа с внешними API (Gemini, OpenAI и др.)
- **Бережное отношение к API тратам**: При написании или изменении кода (особенно в cron-задачах, циклах и обработчиках ошибок), ВСЕГДА учитывай риск возникновения бесконечных циклов вызова платных API. 
- Убеждайся, что в случае сетевой ошибки, ошибки парсинга или ошибки доступа (например, блокировки бота пользователем) код корректно обрабатывает исключение без повторных массовых вызовов API.
- Если функция работает в фоне или по расписанию, состояние успешности (или окончательного провала) должно обязательно фиксироваться в БД до того, как задача завершится, чтобы избежать бесконечных повторов при следующей итерации.
